# Bilt / Rakuten Dining — full dining checklist from your NYC Instagram collection

Prepared Fri Nov 13, 2026, updated Fri Nov 13, 2026 to add bars and cafés, from the 103-post collection check (155 dining places).
Only 2 places could be publicly verified — see the flags below. Neither program
publishes its full restaurant list, so the only definitive check is searching
each name inside the apps.

## How to check (5 minutes, in-app only)

- **Bilt:** Bilt app → Neighborhood > Dining tab. Rate is restaurant-specific
  in the app; program range is typically 1–3 extra Bilt points / $1.
- **Rakuten Dining:** Rakuten app → In-Store > Dining. Flat 5% cash back
  (or 5x Amex MR / Bilt points if chosen as payout), full bill incl. tax/tip/
  drinks, dine-in only.
- **One-card rule:** a card can be enrolled in only ONE Rewards Network
  program at a time — a Bilt-linked card can't also earn Rakuten Dining on
  the same purchase. Both programs are partly/wholly powered by Rewards Network.
- Work through the list alphabetically; tick a name only when the app itself
  shows it. "Not found publicly" ≠ "not participating."
